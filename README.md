# MD to PDF Converter (Local Pro)

외부 서버 전송 없이 **100% 사용자 컴퓨터 브라우저 메모리 안에서만** 마크다운(`*.md`) 문서를 읽고, 사용자가 지정한 **폰트, 글자 크기, 여백, 스타일을 그대로 유지하여 PDF로 저장**하는 웹 애플리케이션입니다.

---

## 🔒 100% 로컬 보안 원칙 (Zero Server Upload)

- 업로드된 파일은 외부 서버나 클라우드로 **절대 전송되지 않습니다.**
- HTML5 `FileReader` API를 통해 **컴퓨터 브라우저 메모리 내에서만 직접 파싱 및 렌더링**됩니다.
- 회사 기밀 문서나 개인 메모 등 민감한 마크다운 파일도 안전하게 변환할 수 있습니다.

---

## 🚀 실행 방법

별도의 Python, Node.js 설치나 로컬 서버 구동이 전혀 필요하지 않습니다.

1. 본 폴더에 있는 **`index.html` 파일을 더블 클릭**하거나,
2. 웹 브라우저(Chrome, Edge, Whale, Safari 등) 창으로 **`index.html` 파일을 끌어다 놓기**만 하면 즉시 실행됩니다.

---

## ✨ 주요 기능

### 1. 다양한 마크다운 서식 지원
- 제목(H1~H6), 굵은 글씨, 기울임, 취소선, 링크, 이미지
- 코드 블록 구문 강조(Syntax Highlighting) 및 인라인 코드
- 표(Table) 자동 정렬 및 테두리 서식 보존
- 체크리스트(Task List, `[ ]`, `[x]`) 렌더링
- 인용구(Blockquote) 및 구분선

### 2. 폰트 및 스타일 정밀 커스텀 (PDF 변환 시 100% 유지)
- **한글/영문 폰트 선택**: Pretendard, 본고딕(Noto Sans KR), 본명조(Noto Serif KR), 나눔명조, 시스템 기본 글꼴 등
- **글자 크기 조절**: 12px ~ 24px 슬라이더
- **줄 간격(행간) 조절**: 1.3 ~ 2.3
- **용지 여백**: 좁게(12mm), 보통(20mm), 넓게(28mm)
- **용지 규격**: A4, Letter, A3
- **문서 테마**: 클린 화이트, 서적 세피아, 모던 슬레이트, 학술 세리프

### 3. 두 가지 PDF 저장 옵션
1. **⚡ 빠른 PDF 다운로드 (`Ctrl + S`)**  
   - 버튼 클릭 한 번으로 컴퓨터의 `다운로드` 폴더에 즉시 `[파일명].pdf`로 저장됩니다.
2. **🖨️ 고화질 벡터 인쇄 / PDF 저장 (`Ctrl + P`)**  
   - 브라우저 인쇄 대화상자의 "PDF로 저장" 기능과 연동되어, 텍스트 복사 및 검색이 가능한 고해상도 벡터 PDF를 생성합니다. (표나 코드블록이 중간에 잘리지 않도록 페이지 분할 방지 최적화 적용)

### 4. 편리한 편집 및 뷰어 기능
- 파일 탐색기 선택 및 전체 화면 **Drag & Drop** 지원
- **3단 뷰 모드**: 미리보기 전용 / 분할(편집+미리보기) / 편집기 전용
- 배율 확대/축소(Zoom) 기능 (50% ~ 175%)
- 실시간 글자 수, 단어 수, 예상 읽기 시간 카운터
